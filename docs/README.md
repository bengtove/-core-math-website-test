# CoRE-Math website documentation

This directory is the authoritative working documentation for the CoRE-Math
website. It explains how the live site is maintained, how content is prepared,
and how its design and automated processes work. The website is published from
this repository at [www.africaeuropecoremath.org](https://www.africaeuropecoremath.org).

Dropbox remains the archive for source material: original photographs,
permissions correspondence and rights evidence, historical screenshots,
backups, and broader CoRE-Math communication policies. Do not treat a web
image in this repository as the archival original or as evidence of reuse
rights.

### For colleagues contributing material

Website source and its active guidance are kept here in GitHub. Send proposed
text, dates, URLs and source material to the website maintainer through the
team's agreed channel; do not edit the published site directly. State the
intended page or section, the source of factual claims, and whether the change
is time-sensitive.

For a news item, provide a proposed title, publication date, short text,
relevant internal/external links and a concise listing excerpt if available.
For an event, provide its title, exact start and end dates, location,
organiser, description and authoritative link. Dates determine whether an
event is shown as upcoming or past, so uncertainty should be stated rather
than guessed.

For a photograph, provide the original file and its event, date, location,
photographer, copyright holder, requested credit, source and explicit web-use
permission or licence. If any of this is unknown, say so: public availability
does not grant reuse permission. Technical help or a change to the site itself
should be requested from the person or team administering this GitHub
repository; no named support contact is assumed here.

## Content management

[Metadata](metadata.md) is the reference for the collections and data files.
Use stable identifiers rather than titles when creating relationships between
events, programmes, projects and research groups. The relevant automated
behaviour is described in [Automations](automations.md).

## Administration

[Website administration](website-administration.md) is the practical guide to
publishing, domain management, recovery and independent backups. It links to
the configuration and workflows that must be checked before any infrastructure
change. Do not record passwords, tokens, private permission correspondence or
other credentials in this repository.
