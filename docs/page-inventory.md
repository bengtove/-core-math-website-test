## Structural observations

1. **University profiles are deliberately non-addressable.** All 17 profiles are accessible from the Network page and work as dialogs, but they cannot be bookmarked or shared as individual profile pages. This is consistent with the current dialog design; it is only a limitation if deep links to individual nodes become a requirement.

2. **Events are structurally coherent.** The Events collection is the single dated-activity source. Current events are exposed through News & Events and associated programme/project/research-group pages; past ones are reachable through the dedicated archive. The four legacy redirects preserve older project-like event URLs without maintaining duplicate content.

3. **Catalogue-only collaborations are an intentional mixed level of detail.** The Programmes & Projects landing page lists seven collaborations without detail pages alongside six projects with detail pages. This is not broken, but visitors cannot learn more about those catalogue-only items within the site. Creating pages should be an editorial decision, not an automatic structural change.

4. **Contact is footer-only by design.** It has a stable public route and appears in the global footer, but not in the main navigation. This is a reasonable compact-navigation choice rather than an orphan page.

5. **No duplicate standalone school/project pages remain.** The current historical and upcoming schools are Events, with legacy project URLs redirected to their authoritative event records. The CoRE-Math Schools page remains the continuing programme context, and the previous-schools archive remains separate.
